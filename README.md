# UIS Web Map Service

This project provides a basic skeleton for a Spring MVC application using Maven.
It demonstrates how to serve a simple Leaflet-based map and can be extended for
Urban Information System (UIS) functionality.

## Build

Ensure Maven is installed and run:

```bash
mvn package
```

The resulting WAR file will be located in `target/` and can be deployed to a
servlet container such as Tomcat.
